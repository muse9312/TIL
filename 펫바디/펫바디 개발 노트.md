# 펫바디 개발 노트
----

반려동물 통합 관제 플랫폼(펫바디)을 개발하면서 만난 기술 주제들의 인덱스.
노트 본문은 프로젝트가 아니라 **주제 폴더**에 두고, 여기서 링크로 모은다.
프로젝트 맥락으로 한 번에 찾고 싶으면 `#펫바디` 태그로 검색.

## 프로젝트 한 줄 요약

AI 영상분석 엔진을 공유 자산으로, 보호자(B2C) · 위탁시설/동물병원(B2B) · 지자체(B2G)를 데이터로 연결하는 펫케어 관제 플랫폼.
개발은 **B2B 먼저**, 그중에서도 **위탁시설(유치원·호텔·카페)** 부터.

## 기술 스택

| 영역 | 선택 |
| ----------- | ----------- |
| 서버 | Fastify 5 + TypeORM + MySQL |
| 프론트 | React + Vite + TypeScript ([[싱글 페이지 애플리케이션(SPA)]]) |
| 모바일 앱 (펫바타) | [[React Native]] + [[Expo]] SDK 57 (읽기 전용 화면만 [[웹뷰]]) |
| 라우팅/상태 | [[TanStack Router]] + [[TanStack Query]] + [[zustand]] |
| 실시간 | SSE |
| 배포 | Docker 멀티스테이지 빌드 |

### 모바일 앱 (펫바타)
- [[펫바타 앱 - React Native 채택 근거]] — RN 전체 + 읽기 전용 화면만 웹뷰. 위젯·Live Activity가 네이티브라 앱 하나로 통일 (2026-10-12 결정)
- [[React Native]] — React로 OS 네이티브 뷰를 그린다. 웹 React와 다른 건 UI 계층뿐. 0.82부터 New Architecture 전용
- [[Expo]] — RN 위의 프레임워크. SDK 57 = RN 0.86. CNG·config plugin·동적 설정·Expo Go vs Development Build
- [[홈 화면 위젯]] — OS가 그리는 정지 사진. iOS 리로드 예산 하루 40~70회, Android 30분 하한, 앱 꺼짐 갱신은 백엔드 푸시
- [[EAS]] — Expo의 빌드·배포 클라우드. `petbody-client-app` ↔ `@seraaa/petvatar` 연결(2026-10-15), Organization 이전 예정
	- [[EAS Build]] — 클라우드 Mac으로 iOS 빌드 + 서명. 테스터 배포는 `distribution: internal`
	- [[EAS Submit]] — 스토어 업로드 자동화. 메타데이터·심사 제출은 안 해 줌
	- [[EAS Update]] — JS만 심사 없이 배포. RN 채택 근거의 핵심. runtimeVersion으로 호환성 구분
- [[앱 출시 프로세스 (iOS · Android)]] — 계정 준비(D-U-N-S)→빌드·서명→TestFlight·테스트 트랙→심사→단계적 출시. 심사 체크리스트(계정 삭제·4.8 로그인), EAS vs 내부 빌드 비교

### 협업 규칙 (초안 · 팀 논의 전)
`CONTRIBUTING.md` 를 초안으로 써두고 검토 중이다. **확정된 규칙이 아니다.**
- [[Conventional Commits]] — 스펙 v1.0.0 정리. scope 를 [[Feature-Sliced Design(FSD)]] 레이어로 쓰는 안, `!` 를 백엔드 API 계약 파괴 신호로 전용하는 안 (둘 다 **미확정**)
- [[Git 브랜치 전략]] — 3인 팀 · 사내 GitLab. GitHub Flow 를 제안 중이고, `main` 브랜치 보호를 실제로 걸지가 미결
- [[커밋 컨벤션 강제 도구(husky · lint-staged · commitlint)]] — **셋 다 미설치.** 붙일지 여부가 초안의 최대 미결 항목

### 아키텍처 (검토 중)
- [[Feature-Sliced Design(FSD)]] — **도입 여부 미결.** 레이어·슬라이스·세그먼트 3층과 import 규칙, 지금 도입할 때의 이해득실
- [[폴더 구조 전략]] — 기술별 / 기능별 / FSD 비교. 어느 규모에 뭐가 맞나
- [[FSD와 파일 기반 라우팅의 충돌]] — `pages` 레이어와 [[TanStack Router]]의 `routes/`가 겹치는 문제와 두 해법
